# # BCA_SEM_1_MINOR_PR — C Programs

Beginner C programs from BCA Semester 1 coursework.

## Programs

### hello_world.c
Classic first program — prints "Hello, World!" to the console.

### area_circle.c
Takes the radius of a circle as input and calculates its area using the formula π * r².

### area_rectangle.c
Takes length and breadth as input and calculates the area of a rectangle (length * breadth).

### perimeter_rectangle.c
Takes length and breadth as input and calculates the perimeter of a rectangle (2 * (length + breadth)).

### a_p_user.c
Takes user input to calculate area and perimeter.

### simple_interest.c
Takes principal amount, rate of interest, and time as input, then calculates simple interest using the formula (P * R * T) / 100.

## How to run

Compile and run using GCC:

gcc program_name.c -o program_name
./program_name

Or simply run directly in VS Code using the Run button.

## Note
.exe files are excluded from this repo via .gitignore — they are compiled binaries generated locally and not needed for others to read or run the source code.
